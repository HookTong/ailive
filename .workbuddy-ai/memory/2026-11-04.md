# 2026-11-04

## 音色库收口：VoiceProvider 统一合并内置预设与自定义音色

- `VoiceContext` 里 `customVoices` 改为 `voices`（内置 + 自定义合并结果），消费方不再自己拼数组。
- `VoiceProvider` 内 `const voices = useMemo(() => [...VOLCENGINE_VOICE_PRESETS, ...customVoices], [customVoices])`；`customVoices` 降级为 Provider 私有 state，`addVoice` / `deleteVoice` 补上 `useCallback` 并纳入 value 的依赖（原先没进依赖数组，memo 里存的是首帧闭包）。
- `VoiceSetting` 去掉 `customVoices` prop，改从 `useVoice()` 取 `voices`；`ModelControlPanel` 删掉 `VOLCENGINE_VOICE_PRESETS` import，`handleVoiceSpeak` 不再二次查找（preset 本来就来自合并列表，直接透传）。
- `ModelProvider` 在 `VoiceProvider` 外层拿不到音色列表，3 处 `VOLCENGINE_VOICE_PRESETS[0].id` 改为 `api.ts` 新导出的 `DEFAULT_VOLCENGINE_VOICE_PRESET_ID` 常量。
- 校验：`grep VOLCENGINE_VOICE_PRESETS` 只剩 `hooks/useTts/api.ts`（定义 + 派生默认 id）与 `VoiceProvider/index.tsx`（合并）。`tsc -b --force` 与 `vite build` 均 exit 0；Playwright 实测初始 5 个内置、添加后 6 个、删除后回到 5 且 localStorage 清空，内置「活力」发声请求带 `X-Api-Resource-Id: seed-icl-2.0` + `speaker=ICL_uranus_zh_female_huoponvhai_tob`，自定义音色带 `seed-tts-2.0`，说话中气泡与按钮文案（`正在说话…`）都正常。
- 踩坑：本机 vite 只监听 `[::1]:5173`，Playwright 用 `127.0.0.1` 会 `ERR_CONNECTION_REFUSED`（curl 返回 502），脚本必须用 `http://localhost:5173/`。
