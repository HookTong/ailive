## 追加：`VolcengineVoicePreset` 类型也移入 presets.ts

- `presets.ts` 现在同时导出类型与预设数组，成为音色领域数据的唯一来源。
- 关键取舍：`hooks/useTts` 不能再引用它（hook 不应反向依赖 contexts），所以在 `hooks/useTts/api.ts` 新增窄类型 `VolcengineSpeechVoice = { voiceType; resourceId?; speedRatio }`，只描述「发起一次合成真正用到的字段」，`synthesizeVolcengineSpeech` 与 `useTts.speak` 都改用它。
- 参数名从 `preset` 改成 `voice`（`synthesizeVolcengineSpeech(text, voice, config)`），内部 `preset.resourceId / voiceType / speedRatio` 同步改名。
- 类型兼容靠结构子类型：`VoiceContext.speak` 仍声明 `(text, preset: VolcengineVoicePreset, modelId)`，把 `useTts` 返回的 `(voice: VolcengineSpeechVoice) => …` 赋给它时，参数按逆变方向检查，`VolcengineVoicePreset` 结构上满足 `VolcengineSpeechVoice`，`tsc` 通过。
- 引用点改为从 `contexts/VoiceProvider/presets` 取类型：`VoiceContext.ts`、`storage.ts`、`VoiceProvider/index.tsx`、`VoiceSetting`、`ModelControlPanel`。
- 校验：`grep contexts src/hooks` 只剩 `hooks/index.ts` 桶文件的转出；`tsc -b --force` / `vite build` exit 0；浏览器冒烟结果与上一轮一致。
